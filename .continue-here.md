### Quick task: consensus_distance.R → Biostrings global alignment
Replaced the ungapped position-by-position comparison in `bin/consensus_distance.R` with a
Needleman-Wunsch global pairwise alignment (`pwalign::pairwiseAlignment(type="global")`).
Gap columns (indels) now count as differences. N/zero-coverage columns still excluded from
the denominator. Output TSV columns unchanged.

Key implementation notes:
- `pairwiseAlignment` moved to `bioconductor-pwalign` package in BioC ≥ 3.19 — must import both `Biostrings` AND `pwalign`
- Existing `'-'` characters stripped from consensus before alignment (pairwiseAlignment requires ungapped input)
- `as.character(pattern(aln))` returns aligned string WITH internal gap chars; terminal overhangs are NOT included (not stored in AlignedXStringSet)
- Terminal gaps are free in pwalign type="global" — minor corner case for tail-trimmed consensuses, negligible for 9.6 kb HCV
- Validated on Thomson dataset (ERR1810447/53/69): all 6 pairs produce identical similarity_pct/n_differences to old algorithm — no internal indels in these samples
