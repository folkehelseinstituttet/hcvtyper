# Requirements: HCVTyper — Strain Model Redraw (REFSEL-01)

**Defined:** 2026-06-12
**Core Value:** A reported minor strain (co-infection) must be backed by orthogonal de novo/BLAST evidence — never on top of a failed major/dominant, never when de novo refutes it as a cross-mapping artefact — while genuine low-abundance co-infections are preserved.

## v3.0 Requirements

Requirements for milestone v3.0 (Strain Model Redraw). Each maps to roadmap phases (continuing at Phase 6).

### Candidate Selection (REFSEL)

- [x] **REFSEL-01**: Reference selection ranks candidates neutrally (`cand_1..cand_n`) by read recruitment, with no major/minor dominance semantics during the run
- [x] **REFSEL-02**: Candidate count is a parameter, default 2 (reproduces today's two-slot behaviour)
- [x] **REFSEL-03**: Each candidate is independently targeted-mapped, replacing the asymmetric `MAJOR_MAPPING`/`MINOR_MAPPING` aliases; `gate_flag`/`minor_call` plumbing becomes per-candidate `confirmation_status`

### Assembly Support (ASUP)

- [x] **ASUP-01**: De novo/BLAST evidence is expressed as per-genotype assembly support (best contig length, BLAST identity/length, k-mer coverage), computed independently of mapping
- [x] **ASUP-02**: Assembly support is joined to candidates at genotype level (parameterized match level), not subtype

### Strain Classification (CLASS)

- [x] **CLASS-01**: Each candidate is classified at the summary step into a strain role: dominant / co-infection / background
- [x] **CLASS-02**: A non-dominant candidate is reported as co-infection only if it clears an abundance floor AND has genotype-level assembly support; otherwise background/artefact ("guilty until corroborated")
- [x] **CLASS-03**: Background/artefact candidates are surfaced explicitly with their reason (no assembly support / below floor), never silently dropped
- [x] **CLASS-04**: An overall sample call is derived from roles (monoinfection / co-infection / indeterminate)

### Dominance Scoring (SCORE)

- [x] **SCORE-01**: Dominance is a combined score over mapped read count, k-mer coverage, and mapping coverage breadth
- [x] **SCORE-02**: Breadth evenness/uniformity across the genome is weighted strongly in the dominance score (read counts alone are contamination-prone)

### Compatibility (COMPAT)

- [x] **COMPAT-01**: Non-breaking — existing default flags (e.g. `denovo_confirm_minor`) + candidate count default 2 reproduce v1.0/v2.0 reporting
- [x] **COMPAT-02**: Output-filename slot field migrates `.major.`/`.minor.` → `.cand1.`/`.cand2.`, with `bin/summarize.R` parsing updated in lockstep
- [x] **COMPAT-03**: Legacy `Major_*`/`Minor_*` summary columns are aliased for one release alongside the new role-based columns
- [x] **COMPAT-04**: Existing 1a/1b co-infection and 2k/1b recombinant exceptions are preserved

### Validation (TEST)

- [x] **TEST-01**: Regression suite extended to cover candidate ranking, all three role classifications, combined-score dominance, and legacy reproduction; wired into CI

## Out of Scope

Explicitly excluded from v3.0. Tracked for future milestones.

| Feature | Reason |
