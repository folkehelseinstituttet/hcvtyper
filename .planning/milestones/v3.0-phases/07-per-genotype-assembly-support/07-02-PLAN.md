<objective>
Join side of Phase 7 (ASUP-02). Consume the Plan-01 per-subtype `*.assembly_support.csv` and the Phase-6 long-format `*.candidates.csv` in `bin/summarize.R`, and `left_join` assembly support to candidates at genotype level using the parameterized `denovo_match_level` (default genotype). Candidates are the LEFT side (no row loss); a candidate with no genotype-level support resolves to an explicit `assembly_support = "none"` with NA metrics (criterion #3). The legacy minor-coupled path (`apply_denovo_layer()` / `minor_denovo_status` / `coinfection_flag` / `review_flag` / `denovo_minor_*`) stays UNCHANGED and runs in parallel — both the old `denovo_minor_*` columns and the new per-candidate support columns appear in `Summary.csv` this phase (intentional duplication, D-04; removed Phase 8/9).

Purpose: ASUP-02 — genotype-level corroboration signal attached to every candidate, ready for Phase 8. Reproduction anchor (criterion #4): at default flags + N=2, the new join's `cand_2` support equals today's `denovo_minor_contig_length` on the regression fixtures.
Output: `bin/assembly_support_join.R`, summarize.R join + new columns, workflow staging, R test.
