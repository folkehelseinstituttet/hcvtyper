<objective>
Migrate the producer side of the `.major.`/`.minor.` → `.cand{rank}.` filename-slot rename (COMPAT-02, D-01/D-04). This plan changes every place that WRITES a slot-named file or emits a per-rank FASTA channel: the 6 `ext.prefix` closures in `conf/modules_hcv.config`, the FASTA-write loop in `bin/summarize_mapping_to_all_references.R`, and the `parsefirstmapping`/`blastparse` module emits + stubs. It also generalizes the parsefirstmapping FASTA emit from a fixed two-slot pair to an N-FASTA channel so the n_candidates>2 guard can be lifted (workflow-side lift happens in Plan 02).

Purpose: This is half of the COMPAT-02 lockstep. It must land in the same wave as the summarize.R consumer-side parse cutover (Plan 03) — a mismatch silently empties Major_*/Minor_* columns with no crash (RESEARCH Pitfall 1).
Output: All targeted-mapping intermediates and per-rank FASTAs use the uniform `cand{rank}` slot; PARSEFIRSTMAPPING exposes an N-FASTA channel for the Plan 02 fan-out.
</objective>
