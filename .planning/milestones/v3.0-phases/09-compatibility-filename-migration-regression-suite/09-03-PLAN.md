<objective>
Migrate the consumer side of the COMPAT-02 filename-slot rename (D-02): refactor `bin/summarize.R` so it no longer drives Major_*/Minor_* logic off the filename-position-3 `first_major_minor` slot string. Instead, each of the three stats loops recovers the candidate rank by joining its per-file reference token to the already-loaded `candidates_long` frame on `candidate_rank`, and the `cv_by_ref` reference-cleanup strip changes from `_(major|minor)$` to `_cand[0-9]+$`.

Purpose: This is the second half of the COMPAT-02 lockstep with Plan 01 (producer slot rename). It MUST land after Plan 01 (depends_on: 09-01, Wave 2) — if the config emits `.cand1.` but summarize.R still expects `major`, every `case_when(first_major_minor == "major")` returns NA and Major_* columns silently empty with no crash (RESEARCH Pitfall 1, the documented highest-risk integration site).
Output: summarize.R parses `.cand{rank}.` filenames correctly via a candidate_rank join; Major_reference/Minor_reference stay byte-identical so the downstream join keys at L366/L1043 still match.
</objective>
