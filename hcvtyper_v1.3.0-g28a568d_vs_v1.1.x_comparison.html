HCVTyper — v1.3.0-g28a568d vs v1.1.x release comparison

Five NGS runs · 140 samples · de novo-informed strain selection with the new evidence/confidence layer (v1.3.0-g28a568d) vs legacy releases v1.1.5 & v1.1.6 · generated 2026-08-03

Scope. Primary metrics: identified major subtype and resistance results. Secondary metric: minor strain call differences. Coverage / mapping / read-count metrics are out of scope. Source: summary/Summary.csv per run from HCV/2026/HCV_paper_revisjon/ (new) and the matching HCV/2025/ & HCV/2026/ routine result folders (legacy). Read-only — nothing was written to /mnt/N. Samples matched on the ID prefix before -HCV; all 140 samples are present in both versions of every run.
Which column is the call? In v1.3.0 the reported strain identity lives in Major/Minor (and the identical Major_subtype/Minor_subtype). Unlike v1.1.x, these are no longer GLUE-only: when HCV-GLUE cannot be run the mapping subtype is reported instead, with the shortfall recorded in call_confidence. The legacy Major_genotype/Minor_genotype columns are stale in this build — see Section 6. All comparisons below use Major_subtype/Minor_subtype.

  • Major subtype: 134/140 concordant. Six samples differ. Five are gains — legacy reported NA because HCV-GLUE could not be run on the sample, and v1.3.0 now falls back to the mapping subtype (2753256, Sample52K, Sample62K, Sample82K in run 20260521-01; 2768882 in run 20260625-02). All five carry call_confidence=review and an explicit "identity not corroborated" review flag, so the extra information is correctly labelled as provisional rather than presented as a confirmed call. The sixth, Sample51K, is a genuine change and is discussed below.
  • Resistance: 139/140 concordant. All NS3/4A, NS5A and NS5B calls match except Sample51K, where the major/minor swap changes which strain the resistance report is built from (NS3/4A NA→56Y;168Q;170I, NS5B NA→206E). The five GLUE-less samples above produce no resistance output in either version, so they contribute no resistance difference.
  • Sample51K is now reported as a co-infection, not a mis-call. Legacy called a 2c major with a typable 3a minor; v1.3.0 calls a 3a major with a typable 2c minor — the same two strains, dominance reversed (3a: 6,051 reads/100% breadth@10×; 2c: 26,023 reads/98% breadth@10×), both de-novo-confirmed (9,479 bp 2c contig, 3,854 bp 3a contig), flagged review with "major/minor assignment uncertain". This is the sample that the 2026-07-03 dev snapshot collapsed to a 3a monoinfection with the 2c surviving only as a de novo contig; the strain is no longer lost (Section 5.1). The read counts favour 2c as dominant, so the reversal itself still warrants a look.
  • Secondary metric — typable minors. Legacy reported a minor strain in 45 samples, of which 13 were typable=YES. v1.3.0 reports a minor in 16 samples, 11 of them typable: 8 retained, 3 added (Section 3), 5 dropped (Section 4.1). The 29 dropped non-typable minors are the familiar within-genotype-1 subtype bleed-through artefacts.
  • New in this build: an explicit confidence and evidence layer. call_confidence, Major_evidence_state/Minor_evidence_state, human-readable Major_evidence/Minor_evidence strings and per-candidate review sentences (Section 5). Only 38/140 samples reach high confidence; 78 are provisional — almost entirely because of one over-firing trigger (Section 5.3).
Two issues to fix before this build ships. (1) The "de novo found a different-genotype contig" review trigger fires on 72 of 140 samples (51%) with no contig-length floor — median contig 606 bp, 51 of 72 under 1 kb. It accounts for 92% of the cohort's provisional calls (Section 5.3). (2) Major_genotype/Minor_genotype are broken: absent from 2 of the 5 runs, and swapped relative to Major_subtype/Minor_subtype on Sample51K (Section 6). Both are written up for the pipeline repo in Access_Microbiology/Revision_1/hcvtyper_handoff_summary_defects_2026-08-03.md.

5. What changed in the pipeline

Relative to v1.1.x, de novo assembly + BLAST evidence has moved from output-only QC to an input to the strain call (bin/rescue_evaluation.R, bin/classify_roles.R). Relative to the 2026-07-03 dev snapshot documented in hcvtyper_dev_vs_v1.1.x_comparison.html, this build adds a graded evidence and confidence layer and makes the reported subtype independent of HCV-GLUE availability.

5.3 The off-genotype-contig trigger fires on half the cohort

The review sentence "Monoinfection called for candidate N, but de novo assembly found a different-genotype contig (X) — possible missed co-infection or contamination. Please review." fires on 72 of 140 samples (51%), and on every one of them it is the only review sentence emitted. Those 72 samples are 72 of the 78 samples sitting at provisional — i.e. this single rule accounts for 92% of all provisional calls in the cohort.

It has no contig-length, identity or k-mer-coverage floor, so it fires on assembly noise:

Only 28 of the 72 flagged samples had a legacy minor call at all, and the triggering subtype is frequently 2k1b (n=15) or a short 3a fragment (n=20) — the recombinant reference and the commonest run-mate genotype respectively, i.e. exactly the profile expected of low-level index-hopping and mis-assembly rather than true co-infection.

The shortest triggering contig is 142 bp — below even the most lenient floor the pipeline already defines (denovo_min_contig_length = 500), so the trigger is applying no floor at all.

Which floor to gate on

Reading each flagged contig's own record from blastparse/*.assembly_support.csv (all 72 resolved) lets the existing floors be tested directly:

The k-mer-coverage leg is anti-correlated with what this flag should catch, and the rescue floors suppress everything. The three legacy typable=YES minors that v1.3.0 demotes to monoinfection (§4.1) — the cases that most deserve a flag — all sit below k-mer coverage 2.0: 2743986 (4,467 bp 1b, 91.9%, k-mer 1.42), 2726018 (2,787 bp 1a, 93.3%, k-mer 1.97), 2714375 (2,706 bp 1b, 92.6%, k-mer 1.62). The artefacts run the other way: 2622415 (2k1b, k-mer 3,257) and 2605642 (2k1b, k-mer 2,797) are fragments co-assembled off the abundant major. Contig length is the leg that separates signal from noise here.

Recommendation

(a) Gate the trigger on denovo_min_contig_length, and give it a higher effective value. That is the right parameter — this trigger makes a corroboration-style claim — but its 500 bp default is tuned for confirming a minor that mapping already supports, whereas here the contig is the only evidence. At 500 bp the flag still fires on 49/140 samples. Sweep, with "must-keep" = the three legacy-typable minors above:

Either raise the default, or add a dedicated parameter (e.g. review_min_offgenotype_contig_length, defaulting to denovo_min_contig_length) so the confirmation floor and the review floor can be tuned independently.

(b) Exclude the 2k1b recombinant from the "different genotype" test. 13 of the 72 flags are a 2k1b contig against a 1b (or 2k) major. 2k1b is a 2k/1b recombinant reference — its 1b portion is not a different genotype from a 1b major, so these are a pure taxonomy artefact.

Combined, a 2,500 bp floor plus the 2k1b exclusion takes the flag from 72 samples to 6, retaining all three legacy-typable minors. Since no other trigger fires on any of the 72, the suppressed samples would have an empty review_flag and should rise out of provisional.
